## Strict GitHub scope
This repository (`kunal6x/iitm-mad2-learning-project`) is the **only authorized GitHub repository for this learning effort**. Do **not** read, search, modify or otherwise interact with any other repositories. Other repositories contain unrelated work by senior engineers.

## Public-repository safety
The official project instruction explicitly says not to upload project code to a public repository or share it before the final project grade. This repository is currently public. Therefore this repo can hold original **learning notes, plans, checklists, and source links**, but **no graded project source code** until the repository is made private and sharing restrictions are satisfied. Never commit passwords, API keys, credentials, student private information or copyrighted full source documents/screenshots without permission.

## Preservation policy
- Keep authored learning material under `docs/`; independently written graded project code remains off public GitHub.
- After each substantial lesson, update progress/next actions in the session handoff and record concepts, practice tasks, mistakes and viva readiness.
- Record actual student demonstration, not unverified completion.
- Note source-document changes and revisit official instructions before submission.
- GitHub changes occur only on explicit interaction, not automatically in the background.
